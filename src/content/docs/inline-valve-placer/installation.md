# Setup & Requirements

## Requirements

- Autodesk Revit 2022 – 2026
- pyRevit 4.8 or newer
- A Revit model that contains pipes, such as a plumbing model
- The **Ball Valve - 2-6 Inch** family, with the `2"` type, loaded in the project

## Installing

1. Download the installer from the product page.
2. Close Revit.
3. Run the installer and follow the prompts.
4. Start Revit. **Inline Pipe & Valve Placer** appears on the **AutoBim Hub** tab.

## Loading the valve family

If you're not sure the family is loaded, go to **Insert → Load Family** and load **Ball Valve - 2-6 Inch**. Without it the tool stops with `Ball valve 2" type not found`.
