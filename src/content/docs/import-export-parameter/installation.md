# Setup & Requirements

## Requirements

- Autodesk Revit 2022 – 2026
- pyRevit 4.8 or newer
- Excel is **not** required to create the file. The tool writes the `.xlsx` itself. You need Excel, or another spreadsheet program, to edit it

The model you want to work on must be **open in Revit** before you run the tool. It works on one model at a time, the one you have open, so it's always clear which model is being changed.

## Installing

1. Download the installer from the product page.
2. Close Revit.
3. Run the installer and follow the prompts.
4. Start Revit. **Import & Export Parameter** appears on the **AutoBim Hub** tab.
