# Setup & Requirements

## Requirements

- Autodesk Revit 2022 – 2026
- pyRevit 4.8 or newer
- A project with at least one **title block** loaded
- Save a copy of your project first, just in case

## Installing

1. Download the installer from the product page.
2. Close Revit.
3. Run the installer and follow the prompts.
4. Start Revit. **Create Sheets from Unplaced Plans** appears on the **AutoBim Hub** tab.

## Default settings

| Setting | Default | Meaning |
| --- | --- | --- |
| Sheet number prefix | `WV` | New sheets are numbered `WV001`, `WV002`, … |
| Title block | Preferred type, or the first one in the model | Used on every new sheet |
| View fill | 80% | Share of the drawing area the view may fill |
| Title strip | 0.5 ft | Width kept clear on the right for the title block strip |
| Scales | Standard scales from 1 to 2400 | Scales the tool may switch to when a view is too large |
