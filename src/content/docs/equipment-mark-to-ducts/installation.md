# Setup & Requirements

## Requirements

- Autodesk Revit 2022 – 2026, with an HVAC model open
- pyRevit 4.8 or newer

## Installing

1. Download the installer from the product page.
2. Close Revit.
3. Run the installer and follow the prompts.
4. Start Revit. **Equipment Mark to Ducts** appears on the **AutoBim Hub** tab.

## Before you run it

1. **Check your equipment has Mark values.** If an equipment's Mark is blank, its connected ducts will get a blank Comment.
2. **Back up existing duct Comments.** Whatever is already in a connected duct's Comments field is **replaced**, not added to. If you need it, note it down or save a copy of the file first.
