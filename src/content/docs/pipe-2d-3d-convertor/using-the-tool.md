# Using the Tool

Reads a 2D DXF drawing, reports every pipe it finds, and models them as a real pipe system in Revit.

## Basic workflow

1. Open your project in Revit.
2. Click **2D-3D Pipe Convertor** in the ribbon.
3. Choose your options in the dialog and run it.
4. Review the report when it finishes.
