# Installation

## Requirements

- Autodesk Revit 2022 – 2026
- pyRevit 4.8 or newer

## Steps

1. Download the installer from the product page.
2. Close Revit.
3. Run the installer and follow the prompts.
4. Start Revit — **2D-3D Pipe Convertor** appears in the ribbon.
